rproxy.j2の本番設定（dev_onlyブロックを除外）から、upstream_jobmatching_web と upstream_vercel への遷移先パスを整理しました。

## upstream_vercel（Vercel側へプロキシ）

### 共通アセット・API
| Path | 説明 |
|------|------|
| `^/_next/` | Vercel assets参照用 |
| `^/api/jobmatching-web/(.*)$` | vercel→BQロギング用 |

### 募集（公開ページ）
| Path | 説明 |
|------|------|
| `^/job_matching/type_select(/.*)?$` | タイプ選択 |
| `^/job_matching/supplier.*` | サプライヤー |
| `^/job_matching/outsources(/?\|/[0-9a-zA-Z]+\|/[0-9a-zA-Z]+/apply\|/jobs/[0-9a-zA-Z]+)$` | 募集一覧/詳細/応募/jobs |
| `^/job_matching/sitemaps(/.*)?$` | サイトマップ |

### マイページ（応募者側）
| Path | 説明 |
|------|------|
| `^/mypage/job_matching/applied/outsource_applications$` | 応募一覧（ルートのみ） |

### スカウト関連
| Path                                                                                                                                                                                                                    | 説明             |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------- |
| `^/mypage/job_matching/job_talkroom(/?)$`                                                                                                                                                                               | トークルーム一覧       |
| `^/mypage/job_matching/job_talkroom/[0-9a-zA-Z]+(/?)$`                                                                                                                                                                  | トークルーム詳細       |
| `^/mypage/job_matching/job_talkroom/[0-9a-zA-Z]+/(<br>talkroom\|<br>precontract\|<br>precontract/edit\|<br>contracts/order_form\|<br>contracts/work_statement\|<br>precontract_review\|<br>advanced_payment_bill)(/?)$` | トークルーム配下の各種ページ |
| `^/mypage/job_matching/scout(/?)$`                                                                                                                                                                                      | スカウト           |
| `^/mypage/job_matching/job_postings(/?)$`                                                                                                                                                                               | 求人一覧           |
| `^/mypage/job_matching/job_postings/[0-9a-zA-Z]+(/?)$`                                                                                                                                                                  | 求人詳細           |
| `^/mypage/job_matching/job_postings/[0-9a-zA-Z]+/recommended_suppliers(/?)$`                                                                                                                                            | おすすめサプライヤー     |

## upstream_jobmatching_web（Rails側へプロキシ）

### 募集（公開ページ）
| Path                             | 説明     |
| -------------------------------- | ------ |
| `^/job_matching/outsources/add$` | 募集新規作成 |

### マイページ（応募者側）
| Path | 説明 |
|------|------|
| `^/mypage/job_matching/applied/outsource_applications/[0-9a-zA-Z]+(/?\|/talkroom)$` | 応募詳細/トークルーム |
| `^/mypage/job_matching/bookmarks/outsource(/?)$` | ブックマーク |

### マイページ（募集者側）
| Path | 説明 |
|------|------|
| `^/mypage/job_matching/outsources(/?)$` | 募集一覧 |
| `^/mypage/job_matching/outsources/[0-9a-zA-Z]+(/?\|/edit)$` | 募集詳細/編集 |
| `^/mypage/job_matching/outsources/[0-9a-zA-Z]+/outsource_applications/[0-9a-zA-Z]+(/?\|/talkroom)$` | 応募詳細/トークルーム |
| `^/mypage/job_matching/outsources/[0-9a-zA-Z]+/outsource_applications/[0-9a-zA-Z]+/precontract(/?\|/edit/?)$` | 事前契約 |

---

## 補足ポイント
- **`/job_matching/outsources` 系**: 一覧/詳細/応募はVercel、`/add`（新規作成）のみjobmatching_webに残存。
- **`/mypage/job_matching/applied/outsource_applications`**: ルート（一覧）はVercel、`/{id}` 配下はjobmatching_web。
- **`/mypage/job_matching/outsources` 系**: 募集者側マイページは全てjobmatching_web（Vercel未移行）。
- **スカウト/求人/トークルーム関連**: すべてVercelに移行済み。
